# ผลตรวจแคลอรี มื้ออาหารรวม และคำถามดูแลเบาหวาน — 12 ตุลาคม 2026

รุ่น 0.9.0 แก้ “ข้าวกับไข่พะโล้” ให้เป็นบันทึกมื้อเดียว มี `data.components` แยกชื่อ ปริมาณ หน่วย และสถานะอาหาร แคลอรีของมื้อเป็นผลรวมของแต่ละอย่าง ยอดรายวันนับบันทึกนี้ครั้งเดียว ชื่อรายการที่มีข้าวรวมอยู่แล้ว เช่น ข้าวมันไก่ หรือข้าวกะเพราไก่ ใช้ค่าอาหารจานนั้นโดยไม่เติมข้าวเอง

ไม่ระบุปริมาณยังบันทึกได้ โดยแสดงสมมติฐานหนึ่งหน่วยอ้างอิงของอาหารแต่ละอย่าง ไม่เติมปริมาณนั้นลงเป็นข้อเท็จจริงที่ผู้ใช้บอก ตัวอย่างข้าว 2 ทัพพีเล็ก (160 kcal) กับไข่พะโล้ 1 ส่วนสูตรเด็กวัยเรียน (352.9 kcal) รวม 512.9 kcal; แก้ข้าวเป็น 1 ทัพพีแล้วรวม 432.9 kcal ตัวเลขเป็นค่าตามสูตรและขนาดอ้างอิง ไม่ใช่ค่าของทุกจานผู้ใหญ่

หน้าตรวจรายการและหน้าทบทวนแสดงยอดรวมกับรายละเอียดแยกอย่าง เปลี่ยนปริมาณแล้วล้างตัวเลขเก่าทันทีและคำนวณใหม่ ผลตอบกลับล่าช้าไม่ทับค่าล่าสุด การแก้บันทึกเดิมยังเก็บเป็นเวอร์ชันใหม่หลังยืนยัน ลบแล้วไม่นำแคลอรีเดิมมารวม หากบางส่วนไม่มีแหล่งหรือแปลงหน่วยไม่ได้ จะแสดง `partial` พร้อมยอดเฉพาะที่ทราบ ไม่ถือว่าของที่ไม่ทราบมี 0 kcal ไม่มีการเดาว่าข้าว 1 จานเท่ากับกี่ทัพพี

เพิ่มฐานอาหารเป็น 98 รายการ ใช้ประเมินตามหน่วยอ้างอิงได้ 97 รายการ อีกหนึ่งรายการไม่มีหน่วยที่ตรวจได้ เพิ่มอาหารไทยพื้นฐาน 34 รายการจากรายงานจานตัวอย่างกรมอนามัยปี 2551 พร้อมน้ำหนักจริงในรายงานและหน้าตาราง ตัวเลขเหล่านี้สะท้อนสูตรที่เก็บตัวอย่างในรายงาน ไม่ใช่ค่ามาตรฐานทุกสูตรตามร้าน คำว่า “นม” ตีความเป็นนมวัวจืดและใช้ช่วง 90–150 kcal ต่อ 240 มล. ระบุชนิดพร่องมันเนยแล้วใช้ 120 kcal ไม่ใช้แทนกันเงียบ ๆ และไม่จับนมข้นหวานเป็นนมจืด ดู [การตรวจที่มา](nutrition-source-audit.json)

รองรับเศษส่วน ครึ่งจาน จานครึ่ง คำไทยและเลขไทย แก้การตัดชื่ออาหารที่มีคำเติมและตัวอย่าง “วันนี้กินข้าวช้าวเป็นข้าวขาหมู ตอนเที่ยงกินต้มยำกุ้ง” เป็นชื่อสั้นพร้อมช่วงเวลาสองมื้อ วันเมื่อวานส่งต่อไปยังมื้อถัดไปในข้อความได้ ไม่สร้างเวลาเป๊ะเมื่อผู้ใช้ไม่ได้บอก

คำขอจัดแพลนดูแลเบาหวานตอบแนวทางตั้งต้นภาษาไทยพร้อมอ้างอิง NIDDK ได้โดยไม่ต้องรอโมเดลคัดประโยค หากมีข้อมูลยืนยันว่าเป็นเด็ก ตั้งครรภ์ โรคไต หรือดูแลเฉพาะ จะไม่กำหนดจานอาหารทั่วไปแทนแผนทีมรักษา ระบบไม่ปรับยาและไม่บันทึกตารางเอง คำถามนอกเรื่องยังปฏิเสธ ความรู้ส่วนอื่นใช้ RAG และค้น MedlinePlus เฉพาะหัวข้อสาธารณะที่อนุญาต เมื่อโมเดลคัดประโยคไม่ได้แสดงต้นฉบับพร้อมแหล่งแทนข้อความผิดพลาดเดิม ต้นฉบับออนไลน์บางส่วนเป็นภาษาอังกฤษ

## การตรวจจริง

- Python 238 ข้อผ่าน และ HTML/JavaScript จริงใน jsdom 16 ข้อผ่าน รวม 254 ข้อ ดู [Python](nutrition-tests.txt) และ [ส่วนหน้าเว็บ](nutrition-ui-tests.txt)
- ตรวจการบันทึก แก้ปริมาณ ลบ และยอดรายวันของมื้อรวมผ่าน API ในฐานข้อมูลชั่วคราว การ preview ไม่เขียนข้อมูล และการยืนยันยังตรวจเจ้าของ/ความยินยอมตามเดิม
- ตรวจเซิร์ฟเวอร์จริงในเซสชันใหม่ 16 กรณี รวมการค้นหัวข้อ diabetes จาก MedlinePlus ได้ `evidence_found` ไม่ยืนยันบันทึกสุขภาพใด ๆ ดู [ผลเว็บ](nutrition-care-live.json)
- ตรวจผ่านเบราว์เซอร์จริง ได้มื้อเดียว แก้ข้าว 2 เป็น 1 ทัพพีแล้วพลังงานเปลี่ยนจาก 512.9 เป็น 432.9 kcal หน้าทบทวนยังแสดง 1 รายการ ไม่กดยืนยันเพื่อบันทึก ดู [ภาพหน้าทบทวน](nutrition-review-ui.png)

## ชุดส่งต่อโมเดล

จัดเตรียม `dist/ruamwan-ai-macos-0.9.0` เป็น base 4-bit + adapter v2 เฉพาะ intent/menu + backend + ส่วนหน้าเว็บ + ฐานความรู้/กฎที่จำเป็น ใช้ manifest SHA256 ตรวจทุกไฟล์ ไม่รวมฐานข้อมูลผู้ใช้ คุกกี้ ประวัติแชต ข้อมูลฝึก หรือ secrets ไม่ fuse adapter ให้ใช้ทุกงาน เพราะงาน extraction/route/journal ยังมีผลไม่ผ่านเกณฑ์ที่รายงานไว้

ดู [คู่มือเชื่อมเว็บอื่น](../docs/ai-integration.md) และ [ผลโหลดโมเดลจากชุดส่งต่อ](export-model-smoke-v0.9.json) การทดสอบบนเครื่องนี้ใช้ Python environment ที่ติดตั้งไว้แล้ว การติดตั้ง dependency ใหม่บนเครื่องปลายทางยังไม่ได้ตรวจ ชุดส่งต่อนี้ใช้ Mac Apple Silicon + MLX ไม่ใช่ไฟล์รันใน browser หรือ Linux/CUDA โดยตรง

ผลข้างต้นเป็นการตรวจซอฟต์แวร์ ไม่ใช่คะแนนความแม่นยำบนผู้ใช้จริงหรือการอนุมัติทางคลินิก ไม่รับรองว่าไม่มีข้อผิดพลาด ไม่มีการฝึกโมเดลเพิ่มในรอบแก้แคลอรีนี้ บริการยังเป็นต้นแบบในเครื่อง ก่อนให้บริการสาธารณะต้องมีบัญชี/สิทธิ์ถาวร การสำรอง/กู้คืน และการประเมินกับผู้ใช้/ผู้เชี่ยวชาญตามคู่มือ
