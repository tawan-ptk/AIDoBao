# แยกคำถามอาหารจากบันทึก — 0.9.1

ตรวจวันที่13ตุลาคม2026 ก่อนเพิ่ม API/เวลาอัตโนมัติใน0.10.0 สาเหตุคือเส้นทางอาหารหลายอย่างข้ามตัวกรองคำถามและยอมรับ “อะไรดี” เป็นกับข้าวที่ไม่ทราบแคล แก้โดยใช้ guard ร่วมใน journal/chat และเพิ่มรูปประโยคขอแนะนำข้าว/กับข้าวใน wants_menu โดยรักษาคำถามอ่านประวัติและคำถามสุขภาพทั่วไป

ผลก่อนเปลี่ยนข้อกำหนดเวลา: Python275ผ่าน ส่วนหน้า16ผ่าน เรียก server/โมเดลจริง8กรณีผ่าน ไม่ยืนยันบันทึกสุขภาพ ดู [Python](meal-question-python-tests.txt), [UI](meal-question-ui-tests.txt), [API จริง](meal-question-live.json)

“กินข้าวกับอะไรดี” → meal_ideas/read_only ไม่มีร่าง “วันนี้กินอะไรไปบ้าง” → อ่านประวัติ ส่วน “ข้าวกับไข่พะโล้” → ร่างเดียว2components คำถามตรง journal/prepare ไม่เรียกตัวช่วยโมเดลจัดหมวดและไม่สร้างรายการ การตรวจนี้เป็น software regression ไม่ใช่การรับรองความแม่นยำภาษาไทยทุกประโยคหรือ clinical accuracy

ชุด0.9.1 เก็บไว้ตามเดิม รุ่นส่งต่อปัจจุบันและข้อกำหนดเวลาใหม่ดู [รายงาน0.10.0](api-handoff-results.md)
