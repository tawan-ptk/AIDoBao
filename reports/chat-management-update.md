# วิธีใช้และการจัดการข้อมูลในแชต — 0.6.3

คำถาม “แนะนำหน่อยว่าฉันจะถามคุณว่าอะไรได้บ้าง” เคยถูกตัวคัดหัวข้อสุขภาพปฏิเสธ ตอนนี้คำถามความสามารถและวิธีใช้เว็บเป็นหมวด usage_help แยกจากความรู้สุขภาพ ตอบตัวอย่างสั้นพร้อมปุ่มคำถาม ไม่เรียกโมเดลหรือค้นเว็บ คำถามนอกเรื่องเดิมยังปฏิเสธ

## คำสั่งที่รองรับ

- แก้ชื่อ เช่น “แก้ข้าวขาหมูเป็นโจ๊ก” หรือ “เปลี่ยนข้าวขาหมูเป็นโจ๊ก”
- แก้เวลาเริ่ม/เวลาบันทึก เช่น “แก้เวลาบันทึกเดินล่าสุดเป็น 17.00” โดยคงวันเดิม ไม่ย้ายเวลายาในแผนเอง
- แก้ค่าที่บันทึก เช่น “แก้บันทึกน้ำหนักล่าสุดเป็น 68 กก.”
- แก้โปรไฟล์ เช่น “แก้น้ำหนักเป็น 68 กก.”, “แก้ส่วนสูงเป็น 170 ซม.”, “แก้รายการแพ้เป็นไข่และปลา” โดยคงช่องอื่น
- ลบตามชื่อ วัน ช่วงเวลา หรือเวลาที่ระบุ เช่น “ลบบันทึกข้าวขาหมูวันนี้”, “ลบบันทึกมื้อเช้าวันนี้”, “ลบบันทึกเดิน 16.00”
- “ลบบันทึกล่าสุด” หมายถึงรายการที่เก็บหรือแก้ล่าสุด ไม่เรียงจากวันที่เล่าย้อนหลัง
- “ลบบันทึกทั้งหมด” เลือกบันทึกกิจวัตร ส่วน “ลบข้อมูลทั้งหมด” รวมโปรไฟล์ ความยินยอม บันทึก และแผน

คำสั่งทุกอันเป็นข้อเสนอ ไม่ใช่การเขียนทันที แชตแสดงค่าก่อน/หลังเฉพาะช่องที่เปลี่ยน หรือชื่อและจำนวนที่จะลบ จากนั้นกดยืนยันหรือยกเลิกในแชต ไม่ต้องเปลี่ยนหน้า หากชื่อซ้ำจะมีปุ่มให้เลือกทีละรายการ หากไม่พบ เป้าหมายกำกวม หรือเกินจำนวนต่อครั้ง จะให้ระบุเพิ่ม ไม่เดาจากรายการใกล้เคียง การแก้รายการใช้ previous_id และเป็นเวอร์ชันใหม่

## ขอบเขตการลบและความถูกต้อง

API delete-preview ตรวจเจ้าของและรายการเวอร์ชันปัจจุบันก่อนสร้างข้อเสนอ การยืนยันต้องมี CSRF เซสชันเดิมและ confirmed=true ตรวจ revision และรายการแผนซ้ำใน transaction หากข้อมูลเปลี่ยนระหว่างรอ ต้องขอข้อเสนอใหม่

การลบเฉพาะรายการลบทั้งสายประวัติของรายการนั้น แผนที่อ้าง ID เดิม และผลยืนยันที่แคชไว้ซึ่งอาจมีข้อมูลจากแผน การลบโปรไฟล์หรือเวลาที่ล็อกจะลบแผนที่อาจใช้บริบทนั้น โดยแสดงจำนวนแผนก่อนยืนยัน แผนและบันทึกอื่นยังอยู่ ข้อเสนอเก่าของเจ้าของเดียวกันถูกยกเลิกเพื่อไม่ให้ยืนยันข้อมูลที่ลบไปแล้วกลับมา การยืนยันลบซ้ำด้วยกุญแจเดิมให้ผลเดิม ไม่ลบเพิ่ม

หลังลบ แชตล้างข้อความเดิมในแท็บนั้นและรีเฟรชข้อมูล ล้างแบบร่าง/ฟอร์มที่อาจยังแสดงข้อมูลเก่า การลบนี้ครอบคลุมแถวในฐานข้อมูลแอป ไม่ได้ลบไฟล์ส่งออกที่ผู้ใช้เคยดาวน์โหลดหรือสำเนาภายนอก

ไม่มีการใช้โมเดลสร้างรหัสรายการ SQL หรือคำสั่งลบ ใช้ตัวจับคำสั่งที่ตรวจได้ และดำเนินการกับ ID ที่ค้นจากข้อมูลเจ้าของเซสชันเท่านั้น ไม่รับประกันว่าจะเข้าใจภาษาอิสระทุกรูปแบบ ข้อความที่ไม่ชัดเจนต้องระบุเพิ่ม

## การตรวจ

Python ผ่าน 147 กรณี และ UI ผ่าน 14 กรณีด้วย HTML/สคริปต์จริงใน jsdom รวมคำถามตัวอย่าง การเลือกชื่อซ้ำ การแก้ค่าพร้อมหน่วย/เวลา การคงข้อมูลอื่น การยกเลิก การยืนยันในแชต การลบประวัติและแผนที่เกี่ยวข้อง การยืนยันซ้ำ ข้อเสนอเก่า ข้อมูลข้ามเจ้าของ CSRF และการคงโปรไฟล์เมื่อลบเฉพาะบันทึก

ใช้ฐานข้อมูลชั่วคราวสำหรับการทดสอบการแก้และลบ ไม่มีการยืนยันลบข้อมูลจริงของผู้ใช้เพื่อทดสอบ ไม่ได้ตรวจหน้าจอด้วยเบราว์เซอร์จริงในรอบนี้

เซิร์ฟเวอร์จริงรุ่น 0.6.3 ตอบ 200 ทั้งคำถามวิธีใช้ ข้อเสนอแก้น้ำหนัก ข้อเสนอลบทั้งหมด และการปฏิเสธเรื่องดอกไม้ รายงาน live-usage-help-0.6.3.json, live-edit-proposal-0.6.3.json, live-delete-proposal-0.6.3.json และ live-offtopic-0.6.3.json ทดสอบเฉพาะข้อเสนอ ไม่ยืนยันเก็บหรือเปลี่ยนข้อมูลในฐานข้อมูลจริง
