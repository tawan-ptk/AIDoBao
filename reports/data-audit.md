SAV: อ่าน missing ranges จาก metadata ก่อนสรุป รวมรหัส 999/99/9/8/88/0 ตามแต่ละคอลัมน์ ไม่ใช้กฎเดียวทั้งไฟล์ ดู [ผลแจกแจง](thai-distributions.json), [ผล importer](health-import-result.json), dictionary และแบบสอบถามใน reports ข้อมูลการนอน/อาหาร/กิจกรรมเป็น self-report ของพฤติกรรมย้อนหลังตามแบบสอบถาม ไม่ใช่ timeline รายวัน; anthropometrics ระบุวัดโดยอาสาสมัครสุขภาพใน Methods ส่วน BMI/WHR เป็นค่าคำนวณเดิม

แหล่ง SAV เป็น case-control ในบางระกำ ช่วงกุมภาพันธ์–พฤษภาคม 2016 อายุ 30–85 ปี การเลือก controls และการคัดโรคจำกัดการอ้างแทนประชากรไทยทั้งหมด หน่วยรอบเอวใน dictionary กับขนาดค่ารายงานมีความไม่สอดคล้อง จึงไม่แปลงหน่วยเองหรือสร้างกฎสุขภาพจากค่าเหล่านี้ พฤติกรรมที่พบไม่ถูกตีความว่าเป็นพฤติกรรมที่เหมาะสม

Zenodo: บทความ https://f1000research.com/articles/11-332 ระบุแบบสอบถาม 4 ส่วนและข้อมูล chart review; outcome มาจาก FBS ย้อนหลัง 3 ครั้ง แต่ไฟล์ Excel ส่งมอบเป็นรหัส outcome ไม่ใช่ค่าตรวจทั้งสามครั้ง ห้ามนำเกณฑ์งานวิจัยไปใช้เป็นเป้าหมายรักษารายบุคคล คอลัมน์ BMI เป็นรหัสกลุ่ม ไม่ใช่ค่าที่ควรคูณ/แปลงเป็น kg/m² เอกสารประกอบและผลตรวจเพิ่มเติมอยู่ `zenodo-definition-*` เมื่อดาวน์โหลดสำเร็จ

ตรวจ dictionary และ questionnaire ของ Zenodo เพิ่มแล้ว พบข้อขัดแย้งสำคัญ: dictionary ระบุ `dmcontrol` เป็น 1/2 แต่ Excel มี 0 จำนวน 360 แถว และ 1 จำนวน 245 แถว จึงไม่เดาว่า 0 หมายถึงอะไร ส่วน HL ทั้ง 30 ข้ออยู่ในช่วงรหัสที่ dictionary อนุญาต แต่ผลบวก 30 ข้อต่างจาก `totalhl` เดิม 51 แถว ไม่แก้ค่าต้นฉบับหรืออนุมานวิธีถ่วงน้ำหนัก เกณฑ์ `totalhl_g` ยังไม่พบใน dictionary ไม่มี blank cells แต่ยังรับรองไม่ได้ว่าไม่มี missing code ที่ไม่บันทึกไว้ ดู [definition audit](zenodo-definition-audit.json) และต้นฉบับที่ดาวน์โหลดพร้อม hash

ข้อมูลฝึกเก็บ source/document/question ID และไฟล์ต้นทางทุกคู่ ไม่แปล ไม่ paraphrase ไม่เติมคำตอบ AI และไม่ใช้ software fixtures รายการ split และ exact/near duplicate audit อยู่ [training-data-audit.json](training-data-audit.json) มีเพียง 8 คู่ที่คัดตรวจ จึงไม่เพียงพอสำหรับข้อสรุปความแม่นยำภาษาไทยหรือการวางแผนชีวิต

WHO/CDC/แนวทางไทยเป็นแหล่งพิจารณาเพิ่มเติม ยังไม่รวมใน RAG ที่ใช้งาน ไม่อ้างว่าการอ่าน landing page เท่ากับทบทวน guideline เต็ม ดาวน์โหลด CDC ได้ 403 และข้อกำหนด Typhoon รอบล่าสุด timeout เก็บข้อผิดพลาดใน download reports; model card และใบอนุญาตฐานเก็บไว้แล้ว ต้องตรวจเงื่อนไขเพิ่มเติมก่อนเผยแพร่
