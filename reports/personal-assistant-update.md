# ผู้ช่วยร่วมวัน 0.6.0

ปรับบนหน้าและโครงสร้างข้อมูลเดิม เก็บข้อมูลใหม่ใน JSON payload เดิมของ SQLite ไม่ย้ายหรือลบประวัติเดิม และไม่รัน migration บน Supabase

## ใช้งาน

- ช่อง “วันนี้ให้ช่วยอะไรดี” หรือปุ่ม “ให้ร่วมวันช่วย” จากทุกหน้า เปิดแชตเดียวกัน
- “บันทึกตอนเช้ากินข้าวมันไก่ ตอนบ่ายเดิน” เตรียมหลายรายการ ให้ตรวจชื่อ/หมวด/วัน/เวลาก่อนยืนยัน
- “อายุ 40 ปี น้ำหนัก 70 กก. สูง 170 ซม.” เตรียมแก้เฉพาะช่องที่ระบุในโปรไฟล์
- “ฉันแพ้ไข่และปลา” เตรียมรายการแพ้ให้ยืนยัน ไม่ถือว่าข้อความที่ยังไม่ยืนยันเป็นประวัติถาวร
- “ประเมินสุขภาพฉัน” แสดงข้อมูลที่มีและ BMI ผู้ใหญ่เมื่อข้อมูลพอ ไม่วินิจฉัยหรือกำหนดแคลอรี
- “แนะนำเมนูมื้อเย็น” ใช้อาหารที่บันทึกในวันนั้น รายการแพ้ ความชอบ และข้อจำกัดสุขภาพเพื่อคัดตัวเลือก ให้ AI ในเครื่องเลือกจาก ID ที่ผ่านการคัดแล้ว ตรวจ ID ซ้ำอีกครั้งก่อนแสดง
- “จัดตารางพรุ่งนี้เดิน 30 นาทีตอนเย็น” เตรียมรายการในแผน ระบุว่าช่วงตัวเลข 17:00–19:00 เป็นข้อเสนอให้แก้ไข จากนั้นบันทึกรายการและเสนอแผนเพื่อตรวจชนกับรายการที่ยืนยันแล้ว
- “เปิดโปรไฟล์”, “ส่งออกข้อมูลของฉัน”, “ลบข้อมูลของฉัน” เปิดการทำงานที่อนุญาต การลบยังต้องไปหน้าข้อมูลและยืนยันโดยผู้ใช้

ไม่มีการเปิดให้โมเดลเขียน SQL รันคำสั่งระบบ เปิด URL อิสระ หรือเปลี่ยนยา ทุกการเขียนผ่านการตรวจรูปแบบ ความยินยอม และการยืนยันของเจ้าของเซสชันเดิม แผนปฏิเสธการยืนยันเมื่อข้อมูลเปลี่ยนจากตอนเสนอ

## ข้อมูลที่เก็บ

โปรไฟล์ทุกช่องเว้นว่างได้: อายุ น้ำหนักกก. ส่วนสูงซม. โรคที่ผู้ใช้รายงาน รายชื่อยาที่ใช้ การแพ้ ความชอบ เป้าหมาย ข้อจำกัดการเคลื่อนไหว การตั้งครรภ์ และความต้องการดูแลเฉพาะ `allergies=null` คือยังไม่ทราบ; `[]` คือยืนยันว่าไม่มีการแพ้ที่ทราบ ไม่ถือว่าสองอย่างนี้เหมือนกัน

บันทึกจากทางหลักเก็บชื่อสั้นใน `text` และ `data.name`/`data.note` พร้อมข้อมูลแยกช่องที่ทราบ เช่น ปริมาณ หน่วย วันที่ ช่วงเวลา เวลาเป๊ะ วิธีวัด และค่าตรวจ ไม่เก็บข้อความเล่ายาวหรือข้อความหัวข้อช่วงเวลาในหลักฐานถาวร ใช้วันที่พิมพ์ใน Asia/Bangkok หากไม่ระบุวัน ไม่เดาช่วงเวลาหรือเวลาเป๊ะเมื่อไม่บอก สามารถแก้ชื่อและเติมเวลาเป็นเวอร์ชันใหม่ได้ ประวัติเก่าไม่ได้ถูกแก้ย้อนหลัง

ค่า BMI ใช้เฉพาะผู้ใหญ่ที่ทราบอายุ น้ำหนัก ส่วนสูง และไม่ได้ตั้งครรภ์ ไม่แสดงการจัดกลุ่มอ้วน/ผอมหรือใช้ BMI เพียงอย่างเดียวกำหนดอาหาร การเลือกค่าชั่งล่าสุดพิจารณาวันที่วัด ไม่ใช้วันที่แก้ย้อนหลังแทนวันที่วัด

พลังงานของเมนูที่ประกอบขึ้นใหม่เว้นว่างเมื่อยังไม่มีสูตรและปริมาณยืนยัน ข้าวขาหมูและจานอื่นที่ไม่มีข้อมูลตรวจหน่วยได้แสดง “ยังไม่มีข้อมูล” ไม่เดาค่าจากชื่อใกล้เคียง ไม่ดึง ThaiFCD ที่ยังรอสิทธิแบบ bulk

ตัวกรองแพ้คัดส่วนผสมที่ระบุออกก่อนให้ AI เลือก และตรวจผลอีกครั้ง แต่ไม่มีเมนูใดรับรองว่าปลอดสารก่อภูมิแพ้ ต้องตรวจเครื่องปรุงและการปนเปื้อนกับผู้ปรุง รายการแพ้ที่จับคู่ไม่ได้จะหยุดเสนอเมนูจนระบุชัดขึ้น

เด็ก ผู้ตั้งครรภ์ ผู้มีโรคไต ภาวะกลืนลำบากหรือการดูแลซับซ้อนใช้บันทึกและจัดเวลารายการตามแผนผู้ดูแลได้ ระบบยังไม่กำหนดเมนูรักษาโรคหรือแคลอรีเฉพาะบุคคล การจัดเวลาคือการตรวจเวลาชนกัน ไม่ใช่ใบรับรองความเหมาะสมทางสุขภาพ

คำถามความรู้ใช้โมเดลในเครื่องกับหลักฐานเดิม ส่วนหลักฐานออนไลน์ภาษาอังกฤษใช้ AI เลือกประโยคต้นฉบับที่ตรวจได้ เพื่อหลีกเลี่ยงคำแปลแพทย์ผิด ไม่อ้างว่าทุกคำตอบเป็นภาษาไทยหรือมีความแม่นยำทางคลินิกที่ผ่านการรับรอง

## ผลตรวจรอบนี้
